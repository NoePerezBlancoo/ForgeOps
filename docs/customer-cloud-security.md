# ForgeOps Cloud para clientes

ForgeOps es un servicio cloud de mantenimiento industrial accesible desde ordenador, tablet y movil. Cada empresa dispone de un espacio privado y cada persona utiliza su propia cuenta.

Los permisos se asignan segun la funcion de cada usuario: administracion, responsable, tecnico o consulta. Esto permite conocer quien registro, asigno o resolvio una incidencia y mantener una trazabilidad clara.

Los datos de distintas empresas permanecen separados. Las comunicaciones usan HTTPS, los documentos se guardan en almacenamiento privado y las descargas requieren autorizacion. El acceso propietario de ForgeOps esta separado de las cuentas de clientes y protegido con segundo factor.

La plataforma recibe actualizaciones centralizadas, comprobaciones de disponibilidad y copias de seguridad configuradas por entorno. Los procedimientos de recuperacion se prueban periodicamente. Ninguna copia se considera valida hasta comprobar su restauracion.

ForgeOps puede instalarse como PWA sin tienda de aplicaciones. Mantiene una experiencia adaptada a escritorio, tablet y movil y prepara borradores operativos concretos para zonas con conectividad inestable.

Cada cliente administra sus usuarios y permisos. La suspension de una cuenta conserva el historial necesario para saber quien intervino, sin permitir nuevos accesos.

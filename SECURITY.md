# Seguridad

## Versiones soportadas

Durante la fase MVP solo se mantiene la última versión publicada.

## Comunicación responsable

No abras incidencias públicas con credenciales, datos personales o detalles explotables. Comunica el problema de forma privada al propietario del repositorio e incluye el impacto, los pasos mínimos de reproducción y una propuesta de mitigación si está disponible.

Las credenciales incluidas en el proyecto son exclusivamente para el entorno de demostración local y deben sustituirse antes de cualquier despliegue público.
